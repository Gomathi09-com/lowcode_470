# College Canteen Management System

## Project Overview
The College Canteen Management System is a web-based application developed using Zoho Creator to simplify and manage college canteen operations.

## Objectives
- Manage customer information.
- Maintain food menus and categories.
- Process food orders.
- Calculate item-wise and order-wise totals.
- Track payments and inventory.
- Send automated email notifications.

## Technologies Used
- Zoho Creator
- Deluge Scripting
- Zoho Creator Reports
- GitHub

## Modules
1. Customer Profile
2. Food Category
3. Food Type
4. Food Menu
5. Food Order
6. Order Item
7. Payment Record
8. Inventory Transaction

## Key Features
- Automatic customer code generation.
- Automatic item number generation.
- Automatic line total calculation.
- Order total calculation.
- Payment confirmation email.
- New order notification.
- Low stock alert.
- Dashboard and reports.

## Project Files
The Zoho Creator Application IDE export (`.ds`) contains the application structure, forms, reports, workflows and scripts.
